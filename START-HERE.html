دیاستومی روی آیفون؛ نصب از ویندوز

این پوشه سورس اپ است. ابتدا IPA را در GitHub بساز، سپس روی آیفون نصب کن.

۱ — آپلود در GitHub

یک مخزن خالی به نام diastomy-ios بساز. محتویات همین پوشه را از Add file → Upload files آپلود کن؛ نه ZIP و نه پوشهٔ مادر.

پوشه‌های Diastomy، Diastomy.xcodeproj، scripts و .github باید در ریشهٔ مخزن باشند.

۲ — ساخت فایل نصب

Actions → Build iPhone IPA → Run workflow

پس از سبز شدن اجرا، فایل Artifacts با نام Diastomy-iPhone-IPA را دانلود کن. داخل آن Diastomy-unsigned.ipa قرار دارد.

اگر Workflow دیده نمی‌شود، راه‌حل داخل README-FA.md است.

۳ — نصب روی آیفون

Sideloadly رسمی را روی ویندوز نصب کن، آیفون را با کابل وصل کن و IPA را داخل برنامه بکش. امضا با Apple ID رایگان خودت انجام می‌شود و هر ۷ روز تمدید لازم دارد.

رمز Apple ID یا کد تأییدت را در چت یا GitHub قرار نده. نیازی به خرید حساب دولوپر برای این تست نیست.

سهمیهٔ رایگان GitHub Actions باید در حساب موجود باشد. فایل IPA هنوز ساخته و روی آیفون تست نشده است؛ راهنمای کامل و محدودیت‌های این نسخه در README-FA.md آمده است.
